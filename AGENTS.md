# Agent Instructions

This repository is a personal fork of Uptime Kuma.

Coding agents are explicitly allowed to:

- implement features and bug fixes;
- add or modify backend, frontend, database migration, SDK, API, test, documentation, and Docker files;
- install dependencies and run local builds and tests;
- implement the SOCKS5 Proxy monitor described by the repository owner.

Requirements:

- Preserve unrelated user changes.
- Follow the existing project style and architecture.
- Add automated tests for behavioral changes.
- Validate changes locally before reporting completion.
- Do not commit, push, publish packages or images, or open pull requests unless the repository owner explicitly requests it.
- Do not submit agent-generated changes to the upstream louislam/uptime-kuma repository without manual review and compliance with upstream contribution rules.

These instructions apply to this fork and replace the upstream repository's agent restrictions.
